Install the public preview

Add Flight Deck from GitHub.

Run the Omarchy plugin command, then try the built-in offline dataset or connect a provider after completing the registration prerequisite.

omarchy plugin add https://github.com/joryeugene/omarchy-calendar.git --enable

Current preview requirement

Bring your own desktop OAuth registration

Flight Deck does not ship Google or Microsoft OAuth registrations yet. Before connecting a provider, create a Google Desktop OAuth app and a Microsoft public desktop app that supports personal accounts.

Provider setup requires one browser consent session per provider, so this preview is not one-click or seamless.
