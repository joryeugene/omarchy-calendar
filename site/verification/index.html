Exact branch

Use a clean Omarchy profile.

Clone codex/v1.0.0-rc.4-verification, enable the plugin, and open Calendars.

plugin="$HOME/.config/omarchy/plugins/io.github.joryeugene.omarchy-calendar"
git clone --branch codex/v1.0.0-rc.4-verification --single-branch \
  https://github.com/joryeugene/omarchy-calendar.git "$plugin"
omarchy plugin enable io.github.joryeugene.omarchy-calendar --section right

Provider connection

Connect in browser

Choose Google Calendar or Outlook.com, review the read-only permissions, and complete consent. Today and Week should populate after the first successful sync.

Advanced provider override: Contributors can supply a separate desktop registration. A valid local override takes precedence over the bundled metadata.
